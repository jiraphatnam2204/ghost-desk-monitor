1. LD2410 with the **MyLD2410** library (`sensor_data` example), engineering mode on: print energy per range gate 10 times a second (build step C1). The `ld2410` library by ncmreynolds cannot read this data.
2. VL53L1X on 3.3 V: empty chair vs. someone seated, with light and dark clothes (C2).

4. Wire to the draft pin map in build step A4; check each pin against the board's printed labels first.
